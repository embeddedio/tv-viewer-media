# tv-viewer-media

Médias publics (images, vidéos) publiés sur la Page Facebook et le compte Instagram **TV Viewer**.

Ce dépôt est **public volontairement** : Meta (Facebook/Instagram) télécharge les médias depuis
`https://raw.githubusercontent.com/embeddedio/tv-viewer-media/main/<chemin>`.

Le code de publication et la documentation complète sont dans le dépôt privé `embeddedio/autopostmake`.

- `media/` : médias originaux (posts Facebook)
- `media/ig/` : versions adaptées Instagram / stories (9:16 MP4, JPEG)

⚠️ Ne déposer ici que des contenus destinés à être publiés. Aucun secret, aucun document interne.
